What we read

The metadata in your environment describes the current system.

The metadata describes what your organisation built on Dynamics 365: the tables, the rules, the automation, the access and the screens. We read the metadata with the Dataverse Web API. The analysis does not change your environment.

Each name in the table is the name that Microsoft documents. The analysis can reach only the parts that your integration user can see. The standard behaviour of Dynamics 365 is not in the metadata, so the observation sessions show us that behaviour. The scope is Dynamics 365 applications on Dataverse.
